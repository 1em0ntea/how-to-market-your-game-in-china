# Steam 中文区营销

Steam 是很多 PC 独立游戏进入中国市场的主阵地。中文内容平台负责种草，Steam 页面负责承接、转化和长期口碑。

## 商店页

### 中文文案

- 短描述要先讲玩法和差异，不要先讲世界观。
- 避免机翻腔，例如“沉浸在一个令人惊叹的冒险中”。
- 功能点要具体：多少关、多少角色、是否支持合作、是否有肉鸽构筑、是否支持手柄。
- 重要信息放在首屏：中文支持、Demo、发售日期、折扣、玩法标签。

### 图片和 GIF

- 首图要让玩家在 1 秒内看懂类型。
- 截图顺序建议：核心玩法、强反馈、系统深度、内容规模、风格亮点。
- GIF 比长段文字更能解释复杂玩法。
- 中文区截图尽量避免只展示英文 UI。

### 标签

中文玩家依赖标签判断预期。检查相似游戏的标签组合，避免只选宽泛标签。

常见组合示例：

- 动作 Roguelike：动作类 Rogue、轻度 Rogue、弹幕射击、俯视、构筑。
- 模拟经营：管理、建造、自动化、资源管理、基地建设。
- 叙事解谜：剧情丰富、解谜、悬疑、探索、氛围。

## 愿望单

愿望单不是唯一目标，但它是 Steam 发售转化的重要信号之一。中文宣发常见问题是“带来播放量但没有承接路径”。

建议：

- 每个渠道都使用 UTM。
- 视频简介、置顶评论、评论回复都放 Steam 链接。
- 明确 CTA：添加愿望单、下载 Demo、加入测试。
- 对比每次素材发布后的商店访问、愿望单和 Demo 启动。

## Demo

Demo 在中国市场尤其重要，因为玩家和主播都需要可展示内容。

一个适合传播的 Demo 通常具备：

- 前 3 分钟能展示核心乐趣。
- 单局或单段体验可录制。
- 有一个明确的“想再玩一次”的结束点。
- 中文 UI 不出戏。
- 失败、胜利、成长或反转有可剪辑瞬间。

## 新品节与活动

参加活动前要确认：

- Demo 是否稳定。
- Steam 页面是否已经中文化。
- 是否准备了中文公告和 FAQ。
- 是否提前联系了主播和社区。
- 是否有办法追踪活动期间不同来源的效果。

## 发售日

发售当天优先事项：

1. 确认页面、价格、折扣、包体、语言、成就正常。
2. 发布中文公告和发售 PV。
3. 回复高频问题，尤其是 Bug、中文、手柄、存档、性能。
4. 记录差评主题，不要情绪化争辩。
5. 根据实际问题快速热修或解释路线图。
