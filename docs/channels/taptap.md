# TapTap

TapTap 更偏移动游戏和玩家评价生态，但也可以用于中文玩家测试、预约、社区沉淀和口碑观察。

## 适合目标

- 移动游戏预约和测试。
- PC/跨平台游戏收集中文反馈。
- 建立中文页面，方便玩家搜索和讨论。
- 观察相似品类的评价、差评点和玩家语言。

## 页面重点

- 标题、图标、封面和截图要一致。
- 简介要直接说明平台、付费方式、测试状态。
- 更新日志要具体，避免空泛“优化体验”。
- 评论区反馈要及时回应，尤其是设备兼容、付费、账号、网络问题。

## 测试

测试前确认：

- 测试目标：验证玩法、性能、留存、付费还是本地化。
- 测试规模：小范围核心玩家还是公开测试。
- 反馈入口：TapTap 评论、问卷、群、客服。
- 激励机制：是否需要问卷奖励、名单、鸣谢。

## 注意

TapTap 评价对玩家预期影响很大。不要在产品体验未准备好时过早放大曝光。
