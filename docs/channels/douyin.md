# 抖音

抖音适合强钩子短视频。它对素材密度、前几秒吸引力和评论互动要求很高。

## 素材原则

- 3 秒内展示冲突、爽点、反差或结果。
- 画面优先，字幕辅助，不要用长解释开场。
- 单条视频只讲一个点。
- 可以复用一个素材的多种开头测试。
- 评论区问题要转化成下一条视频选题。

## 常见钩子

- “这游戏的机制有点离谱。”
- “我以为是种田，结果越玩越不对劲。”
- “如果把 X 和 Y 合在一起会怎样？”
- “这个 Boss 我打了 37 次。”
- “一个人做游戏最崩溃的瞬间。”

## 指标

- 前 3 秒留存。
- 完播率。
- 收藏和评论质量。
- 主页访问。
- Steam/TapTap 跳转。

## 注意

短视频爆了不等于商业转化。必须提前准备承接路径：主页简介、置顶视频、评论回复、Steam 或 TapTap 链接、QQ群或预约入口。
