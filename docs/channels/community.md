# 微博、贴吧、QQ群与社区

社区渠道的价值不是一次性曝光，而是持续解释、反馈和口碑沉淀。

## 微博

适合：

- 节点公告。
- 转发抽奖。
- PV 和美术图扩散。
- 与媒体、发行商、KOL 互动。

不适合：

- 期待冷启动自然流量。
- 只发 Steam 链接没有话题和素材。

## 贴吧

适合：

- 特定品类或相似游戏玩家聚集地。
- 长帖介绍、开发记录、测试招募。

注意：

- 先理解吧规和社区文化。
- 不要标题党式硬广。
- 最好以开发者身份透明沟通。

## QQ群

适合：

- 核心玩家反馈。
- Demo 测试。
- Bug 收集。
- 发售提醒。

管理建议：

- 置顶常见问题和反馈格式。
- 明确是否允许剧透。
- 记录高频问题，不要只在群里回答一次。
- 对早期玩家保持尊重，他们可能是最早的口碑节点。

## Steam 社区

Steam 讨论区和评测区也属于中文社区经营的一部分。

- 及时回应中文 Bug 报告。
- 准备中文 FAQ。
- 对差评先确认问题，不要辩论动机。
- 更新日志提供中文版本。
