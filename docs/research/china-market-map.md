# 中国市场地图

中国市场不是单一渠道。对独立游戏来说，更实用的划分是：购买平台、内容平台、社区平台、口碑平台、发行与合规体系。

## 常见目标

| 目标 | 主要战场 | 常见指标 |
| --- | --- | --- |
| 验证题材 | B 站、TapTap、抖音、小红书、QQ群、Steam 讨论区 | 评论质量、收藏、试玩反馈、转发、愿望单 |
| 增长愿望单 | Steam、B 站、主播、社群、媒体、节日活动 | 愿望单、商店页访问、UTM、Demo 启动 |
| 获取反馈 | Demo、Playtest、TapTap 测试、QQ群、问卷 | 留存、差评原因、通关率、问卷完成率 |
| 首发转化 | Steam、KOL、直播、折扣、社群提醒 | 销量、转化率、评测数、退款率 |
| 长尾口碑 | Steam 评测、B 站攻略、社区二创、更新日志 | 好评率、UGC、复购 DLC、长尾流量 |

## 渠道角色

### Steam

多数 PC 独立游戏的商业闭环仍在 Steam。中文社媒的目标通常不是直接成交，而是把玩家带到 Steam 页面、Demo、愿望单或评测。

### B 站

适合中长视频、实况、开发日志、玩法解释、PV、主播试玩和社区讨论。B 站用户愿意看“为什么好玩”和“开发者怎么想”，但对硬广敏感。

### TapTap

更偏移动游戏和预约/测试生态，但 PC/跨平台游戏也可以把它当成中文玩家反馈池、评分池和发现渠道之一。

### 小红书

适合视觉风格强、角色强、生活方式表达强、女性向或情绪体验突出的游戏。关键词、封面和笔记语气比传统游戏媒体文案更重要。

### 抖音

适合强钩子、强反差、强反馈的短视频素材。素材需要在几秒内让人明白“这游戏有什么爽点/怪点/美点”。

### 微博、贴吧、QQ群

微博适合节点公告和话题扩散；贴吧适合特定品类或 IP 社区；QQ群适合核心玩家、测试反馈和高频沟通。

## 品类差异

| 品类 | 更容易传播的素材 | 常见风险 |
| --- | --- | --- |
| Roguelite / 生存 / 建造 | 系统组合、爽点、Build、反转局面 | 同质化，需要一句话差异 |
| 解谜 / 叙事 | 氛围、谜题片段、主题、反转 | 剧透控制，视频不易展示完整乐趣 |
| 恐怖 | 反应、气氛、主播传播 | 审核、尺度、低质 jump scare 观感 |
| 模拟经营 | 成长曲线、装修、数值爆发 | 前期观感慢，截图要足够清楚 |
| 视觉小说 / 女性向 | 角色、台词、画风、CV、情绪 | 本地化质量和社区语气非常关键 |
| 硬核动作 | 操作反馈、Boss、挑战、速通 | 难度与新手门槛需要解释 |

## 一个实用判断

如果你只能投入很少时间，优先回答三件事：

1. 中文玩家一眼能不能看懂你的核心卖点？
2. Steam 页面是否已经能承接中文流量？
3. 你是否有一个可试玩、可录制、可讨论的片段？

没有这三点，渠道投入通常会变成低效噪音。
