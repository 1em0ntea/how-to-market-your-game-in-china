# 指标

营销指标的作用是帮助你做选择，而不是制造虚假的安全感。

## 基础漏斗

```text
曝光 -> 点击 -> 商店页访问 -> 愿望单/Demo -> 购买 -> 评测 -> 长尾传播
```

## 推荐追踪

| 阶段 | 指标 | 用途 |
| --- | --- | --- |
| 内容 | 播放、完播、收藏、评论质量 | 判断素材是否有吸引力 |
| 跳转 | UTM 点击、商店页访问 | 判断渠道是否能导流 |
| 转化 | 愿望单、Demo 下载、购买 | 判断页面和产品承接 |
| 体验 | Demo 完成率、退款率、差评主题 | 判断产品问题 |
| 口碑 | 好评率、攻略、二创、社群活跃 | 判断长尾潜力 |

## UTM 命名建议

```text
utm_source=bilibili
utm_medium=video
utm_campaign=demo_launch_2026_06
utm_content=trailer_v1
```

渠道示例：

- `bilibili`
- `taptap`
- `xiaohongshu`
- `douyin`
- `weibo`
- `qq_group`
- `kol_name`

## 不要只看播放量

播放量高但愿望单低，常见原因：

- 素材娱乐性强，但玩家不知道游戏名和入口。
- 商店页没有中文，承接失败。
- 视频吸引了泛人群，不是目标玩家。
- Demo 或页面看起来和视频承诺不一致。
- CTA 不清楚。
