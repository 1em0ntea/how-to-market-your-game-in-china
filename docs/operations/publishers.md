# 发行商合作

发行商可以带来资金、经验、渠道、媒体、平台关系和本地化支持，也可能带来控制权、节奏和收益分配问题。

## 什么时候考虑发行商

- 你需要预付款支持开发。
- 你缺少营销、商务、本地化或平台经验。
- 游戏需要大量主播、媒体、广告或展会资源。
- 你想进入国内移动渠道或更复杂的合规链路。

## 什么时候谨慎

- 对方无法解释具体会做什么。
- 合同只写“推广资源”但没有交付。
- 授权地区和期限过宽。
- 分成口径不清楚。
- 账号、商标、素材归属不清楚。
- 你还没有验证核心玩法，却希望发行商解决一切。

## 尽调

看：

- 对方发行过哪些同品类游戏。
- 这些游戏的 Steam 评测、中文社区和发售节奏。
- 是否能联系到合作过的开发者。
- 对方是否理解你的品类和目标玩家。
- 对方是否愿意给出具体计划和预算范围。

更多问题见 [发行商沟通问题清单](../../templates/publisher-questions.md)。
