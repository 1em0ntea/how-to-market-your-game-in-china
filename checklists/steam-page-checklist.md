# Steam 商店页自查表

## 基础

- [ ] 支持简体中文的地方都已标注正确。
- [ ] 短描述不是机翻，能在 1-2 句话内说明玩法。
- [ ] 首图能看出游戏类型。
- [ ] 截图包含中文 UI。
- [ ] Trailer 前 10 秒展示核心玩法。
- [ ] 标签和相似游戏匹配。
- [ ] 系统需求、控制器支持、联网需求清楚。

## 转化

- [ ] 页面首屏有明确 CTA：愿望单、Demo、购买或关注。
- [ ] Demo 链接和说明清楚。
- [ ] 特色列表不是空泛形容词。
- [ ] 动图展示了核心循环。
- [ ] FAQ 覆盖中文玩家常问问题。

## 追踪

- [ ] B 站、TapTap、小红书、抖音、微博等链接使用 UTM。
- [ ] 每次活动有独立 campaign 名称。
- [ ] 记录发布前后的愿望单变化。
